# Mini Calculadora

Una calculadora sencilla hecha con HTML, CSS y JavaScript. Permite hacer operaciones básicas y usar algunas funciones del objeto `Math`.

## Funcionalidades

- **Con dos números:** suma (`+`), resta (`-`), multiplicación (`x`), división (`÷`) y potencia (`^`).
- **Con el primer número:** raíz cuadrada (`√`), valor absoluto (`|x|`), `round`, `floor` y `ceil`.
- **Sin números:** `random` genera un número aleatorio entre 0 y 1.
- Control de errores: avisa si se intenta dividir entre 0 o calcular la raíz de un número negativo.

## Cómo usarla

1. Descarga o clona el repositorio.
2. Abre el archivo `index.html` en tu navegador.
3. Escribe uno o dos números y pulsa el botón de la operación que quieras.
4. El resultado aparece debajo de los botones.
